# GRT Faculty Records Register – User guide

**Login:** after the intro choose
* **Teacher Access** – no password; only the **Add Teacher** section (a teacher adds / checks their own sheet).
* **Admin Login** – password (default `grtcse@1234`, 👁 eye shows it) → full access. Change it with **Change Password**.
**Logout** returns to this choice.

1. Choose the **Academic Year** (2001-2002 … 2099-2100) and semester in the yellow bar (e.g. *2026-2027 (Odd Semester)*). For another year press **✎ Edit year** and type it (e.g. 2033, 2100). Everything works on that semester.
2. **Add Teacher** – type the name.
   * New teacher → blank Faculty Data Sheet opens (photo, personal details, Anna University / AICTE / APPAR IDs, qualification, experience, publications, conference, workshop, FDP, NPTEL, patents). Press **Save**.
   * Existing teacher → pick the name from the list: all data is **fetched automatically** from their latest earlier semester. Edit what is new and press **Save**.
3. **Search** – all teachers of the semester in one table. Click a row to see everything and download PDF / Word / Excel.
4. **Update** – pick a teacher, change anything, **Save Changes**. Also **Relieve**, **Delete**, download.
5. **Relieve** – the teacher left the college. Data stays in that semester and earlier ones, and is **not carried into later semesters**. **Relieved** tab lists them; **Reinstate** undoes it.
6. **Download Excel** (top) – the whole register of the selected semester, with each teacher's **profile photo** in the *Photo* column.
7. **⬇ Install App** – puts the register on your phone / computer like a normal app (Android, iPhone / iPad, Windows, Mac, Linux). It also opens without internet.
8. **⚙ Settings & Guide** – About, How to Use, User Guide, How to run in VS Code, Backup / Restore, and **Download Source Code ZIP**.

**Storage rules:** one teacher's record (all details + photo, compressed) is kept within **50 KB** per semester. NPTEL certificates (picture, or PDF up to **5 MB**) are stored separately.
Downloaded sheets carry the GRT logo header and the *Academic Year : …(Odd/Even Semester)* line.
**Your data lives in the shared online database – the same on every phone and computer. A backup now and then is still wise (⚙ → Data & Backup).**
